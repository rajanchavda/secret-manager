How It Works

Three steps. Zero plaintext on disk.

Keep linters, TypeScript, and static tools happy with decoy placeholders, while injecting real keys directly into process RAM on Touch ID tap.

Step 01

Lock with Touch ID

Run sec lock .env or right-click in Finder. Encrypts real secrets into .env.vault with AES-256-GCM. Replaces disk .env with sanitized dummy placeholders (API_KEY=locked_by_sec).

$ sec lock .env
Step 02

Tap Sensor

Prefix your command with sec (e.g. sec npm run dev). Touch ID prompts once for your physical fingerprint. Apple Silicon hardware decrypts secrets strictly behind closed doors.

👆 Physical Touch ID Tap
Step 03

In-Memory Execution

Secrets are injected directly into child process RAM (process.env). Plaintext never touches your storage drive, and secrets self-destruct as soon as the process exits.

RAM Only · Zero-Cache

FAQ

Frequently Asked Questions

Quick answers to common questions about Apple Silicon biometrics and threat protection.

Is Secret Manager really 100% free? Are there any hidden costs?

Yes! Secret Manager is 100% free and open-source under the MIT license. There are no subscriptions, no paid upgrades, no feature locks, and no cloud backends. Everything—the native Swift CLI binary, the Finder Quick Actions, and the complete Secret Manager macOS desktop application—is completely free forever.

How does the AI Agent Radar detect agents like Cursor or Claude?

Secret Manager connects directly to macOS FSEvents and process telemetry. When an AI tool (such as Cursor's background indexer, Claude Desktop's bash tools, or GitHub Copilot) reads your project's .env file, the radar intercepts the notification and logs the agent name, timestamp, and target file. It gives you instant verification that the agent only received the decoy placeholders (locked_by_sec) while real keys remained safe inside Apple's Secure Enclave.

What happens to my IDE and linters when `.env` is locked?

When sec lock runs, it inspects your .env keys and replaces their values with locked_by_sec. This keeps the file syntactically valid. ESLint, Prisma schema validators, TypeScript types, and dotenv parsers continue to function without crashing.

Does it work when my MacBook lid is closed (clamshell mode)?

Yes. Apple's LocalAuthentication framework automatically falls back to an Apple Watch biometric tap, Touch ID on an external Apple Magic Keyboard, or your Mac login password if the MacBook display lid is closed.
